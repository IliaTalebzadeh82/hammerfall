## Decisions

- `PublicAuctionSnapshot` represents only the public payload, not an event envelope or private maximum. Kafka validates envelope identity separately; Redis validates its own source/revision/write metadata and the shared payload contract. Do not infer command outcome from either derived path.
- `occurred_at` is database wall time at outbox insert. The earlier auction decision instant, transaction start, commit (not separately recorded), publisher delivery/acknowledgment and Redis projection time are distinct. Existing events cannot be relabeled accurately without historical evidence.
- `attr_readonly` is deliberately an application-code accident guard, not a privileged SQL immutability promise. Publishers may update only their retry/ack fields. The SQL type/JSON CHECK protects structural event shape without duplicating full public semantics in PostgreSQL.
- The delayed-claim test uses a one-second lease and an actual blocking PostgreSQL transaction lasting longer than that lease. The token/cursor predicates already protect stale advance/release and concurrent renewal; expired pages can still duplicate bounded maintenance work.
- Production host filtering is a safe default with explicit deployment configuration. It does not substitute for planned authentication/authorization or make the API public-ready.
