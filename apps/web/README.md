# Hammerfall web

Next.js App Router foundation. See [running locally](../../docs/running-locally.md)
for setup and [the code map](../../docs/code-map.md) for entry points.

Use `npx shadcn@4.21.0 add <component>` from this directory to add UI primitives.
The initialized base-nova style uses Base UI, Tailwind v4 CSS tokens, and cn.
